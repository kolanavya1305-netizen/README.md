# Bitcoin Market Sentiment vs Trader Performance Analysis

## Objective
Analyze the relationship between Bitcoin Fear & Greed Index and trader performance.

## Datasets
- Historical Trader Data
- Fear & Greed Index Data

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Performed
- Data Cleaning
- Data Merging
- Profitability Analysis
- Sentiment Analysis
- Data Visualization

## Key Findings

| Sentiment | Average Profit |
|------------|-------------:|
| Greed | 87.89 |
| Fear | 50.05 |
| Extreme Greed | 25.42 |
| Neutral | 22.23 |

### Insights
- Greed periods generated the highest average profits.
- Fear periods produced lower profits than Greed periods.
- Neutral periods had the lowest profitability.
- Losing trades exceeded winning trades across all sentiments.

## Conclusion
Market sentiment significantly impacts trader performance. Traders achieved the highest average profits during Greed periods.
